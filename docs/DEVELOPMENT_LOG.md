Найдено при разработке:

- SQLAlchemy записывает Python `None` в JSONB как JSON `null`, а не SQL
  `NULL`: ограничение «у неудачного запуска нет отчёта» не выполнилось бы.
  Исправлено `JSONB(none_as_null=True)`; тест проверяет CHECK в базе.
- Названия демо-товаров содержат цифры («Demo pumps 01»): первая версия
  проверки чисел приняла бы `01` за число без доказательства. Текстовые
  значения доказательств теперь вырезаются перед поиском чисел.
- Настройки модели читаются внутри маршрута, а не зависимостью: иначе
  испорченный `.env` превратил бы `422` в `503` (урок этапа 06).
- При завершении этапа обнаружено повторное создание `OptionEngine`:
  несколько SELECT одной сессии открывали разные соединения и снимки.
  `LazySession` теперь сохраняет один лениво выбранный bind. Два теста
  с пулом из одного соединения и проверка конкурентной записи на
  PostgreSQL подтвердили исправление.
- Глобальное исключение годов пропускало `2000 рублей`, а граница слова —
  `999999руб.`. Годы исключаются только в календарном контексте; суммы
  с единицами и раздел `limitations` проверяются. Защита ограничена
  распознанными числовыми записями и не доказывает смысл утверждения.
