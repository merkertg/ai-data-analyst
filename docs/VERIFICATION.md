### Найдено и исправлено

- Evals сравнивали только число строк пяти таблиц. Теперь до вопросов
  проверяются manifest, хэши и все значения шести таблиц в одном снимке
  только для чтения; изменения сумм или остатков при том же числе строк
  отклоняются. После этой проверки база и CSV должны оставаться неизменными
  до конца прогона: последующие вызовы инструментов используют свои снимки.
- AOV без оплаченных заказов вызывал деление на ноль, а процент с нулевым
  знаменателем записывался как строка `None`. Теперь ожидается `null`, как
  в доказательствах API; изменение неопределённого AOV тоже неопределено.
- Bootstrap принимал токен `viewer`, хотя интерфейс задаёт вопросы и
  сохраняет отчёты. Теперь сохраняется только рабочий `analyst`; файл
  устанавливается через уникальный временный файл `0600` и атомарную замену.
  Старый `.tmp` и его симлинк не затрагиваются, временный файл удаляется при
  ошибке. Небезопасные права и симлинк назначения исправляются заменой файла.
- Compose вставлял сырой пароль прямо в URL. Теперь приложение получает
  отдельные параметры подключения и собирает адрес через `URL.create`;
  явный `DATABASE_URL` по-прежнему имеет приоритет для запуска на машине.
- Аудит мог прочитать старый JSON после сбоя pip-audit. Теперь старый отчёт
  удаляется, проверяются новый JSON и согласованность с кодом завершения;
  отсутствие или неверный отчёт приводят к ошибке.
- PDF-счётчик схемы продаж захватывал таблицу токенов из последующего этапа.
  Теперь он считает ровно шесть таблиц экспорта и 28 ограничений схемы продаж.
