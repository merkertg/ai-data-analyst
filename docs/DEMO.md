# Демонстрация AI Data Analyst

Цель показа — пройти понятную цепочку: вопрос руководителя → точные
показатели → разложение изменения по категориям и регионам → ответ
AI-аналитика с доказательствами → сохранённый отчёт. Компания IndustrialFlow
и все данные вымышлены. Режим `mock` работает без ключа OpenAI; числа
считает SQL, а не модель.

## 1. Подготовить перед показом

В корне проекта:

```bash
docker compose up --build --detach --wait --wait-timeout 300
```

Команда сама применит миграции, загрузит демонстрационный набор seed 42
(20 000 заказов за январь–сентябрь 2026 года) и выдаст интерфейсу токен
аналитика. Повторный запуск ничего не перезагружает. Подробности — в
[этапе 10](STAGE_10.md).

Проверь стенд одной командой (нужен Python 3 на машине):

```bash
SMOKE_TOKEN="$(docker compose exec -T ui cat /run/ai-data-analyst/ui_token)" \
  python3 scripts/smoke_stack.py
```

Ожидаемый конец вывода — `Smoke check passed.` Для показа с чистого листа:
`docker compose down --volumes`, затем снова `up`.

## 3. Что объяснить простыми словами

- **Числа считает код.** Модель выбирает инструменты и формулирует вывод;
  каждое число в отчёте сервер сверяет с результатами инструментов
  ([этап 07](STAGE_07.md)).
- **Факт и гипотеза — разные вещи.** Нулевой остаток рядом с падением
  продаж — повод проверить, а не доказанная причина.
- **Доступ по токенам.** Без токена API отвечает 401, роль `viewer` не может
  спрашивать агента ([этап 09](STAGE_09.md)).
- **Качество измерено.** 42 вопроса с ответами, которые независимо считает
  Pandas: эталонный прогон — 42 из 42, демонстрационный провайдер — 17 из 42
  ([EVALUATION.md](EVALUATION.md)).

## 4. Повторить проверки на стенде

Evals прямо в контейнере API (набор CSV генерируется заново тем же seed):

```bash
docker compose exec -T api sh -c \
  'python -m app.data.generate --output /tmp/demo > /dev/null && python -m app.evals --bundle /tmp/demo --provider reference | tail -3'
```

Роль `viewer` и ответ 403:

```bash
docker compose exec -T api python -m app.security issue --name "demo viewer" --role viewer --days 1
TOKEN='ida_…'   # строка token: из вывода выше
curl -s -o /dev/null -w '%{http_code}\n' -X POST http://127.0.0.1:8001/api/agent/runs \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"question": "Почему?"}'
```

Ожидается `403`. После показа отзови токен:
`docker compose exec -T api python -m app.security revoke <id>`.

## 5. Проверка готовности к показу

- `docker compose ps` — `db`, `api`, `ui` в состоянии healthy, `migrate` и
  `bootstrap` завершились с кодом 0.
- `scripts/smoke_stack.py` закончился `Smoke check passed.`
- Порты 8001 и 8502 свободны; иначе `API_PORT=… UI_PORT=… docker compose up`.
- Для настоящей модели: `LLM_PROVIDER=openai`, `OPENAI_API_KEY`,
  `OPENAI_MODEL` в `.env` и `docker compose up --detach api`. Числа
  проверяются так же; живой запуск модели в проекте ещё не измерен.

## 7. Что делать после демонстрации

- `docker compose down` — остановить стенд, сохранив данные.
- `docker compose down --volumes` — удалить данные и токен интерфейса.
- Отозвать выданные для показа токены: `python -m app.security list` и
  `revoke` внутри контейнера `api`.
